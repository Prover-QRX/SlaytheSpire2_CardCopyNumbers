# 同名卡牌编号 · Card Copy Numbers

为《杀戮尖塔 2》战斗中的同名卡牌添加稳定的数字尾缀，方便辨认卡牌、规划操作与记忆 SL 过程。

**作者：祁若泫 · 当前版本：1.2.0**

![同名卡牌编号封面](Workshop/image.png)

[Steam 创意工坊](https://steamcommunity.com/sharedfiles/filedetails/?id=3800734754) · [反馈邮箱](mailto:1526443128@qq.com)

## 功能

- 同名牌显示为 `打击 #1`、`打击 #2` 等，支持初始卡组和战斗中新生成的卡牌，包括感染等状态牌。
- 编号跟随卡牌保留，抽牌、弃牌、消耗、洗牌和升级不会改变编号。
- 普通牌堆浏览时，同名牌按数字递增显示，方便查找。
- 兼容“随机数预测”的冻结之眼，保留真实抽牌顺序，便于对应卡牌编号与牌堆位置。
- 无需 BaseLib、RitsuLib 或其他前置模组，无需额外设置。

本模组不改变卡牌效果、实际抽牌顺序或随机结果。

## 编号显示规则

每名玩家、每场战斗独立编号。

| 情况 | 显示方式 |
| --- | --- |
| 本场某种牌只分配过 `#1` | 隐藏编号，显示原名 |
| 该名称已经分配过 `#2` | 该组编号持续显示，包括原来的 `#1` |
| 同名牌减少，只剩一张 | 已显示的编号继续保留 |
| 卡牌消耗、被变化或移出战斗 | 旧编号仍被占用，新生成的同名牌继续递增 |
| 进入下一场战斗 | 重新编号 |

例如，感染 `#1`、`#2` 都被变化掉后，下一张感染会显示 `#3`，不会重新使用 `#1`。

**编号代表卡牌身份，不代表抽牌位置。** 出现缺号是正常现象。

## 安装

以下为 Windows Steam 版的安装方式。请选择工坊订阅或本地安装其中一种，避免同名版本重复安装。

### 方法一：Steam 创意工坊

1. 打开[本模组的创意工坊页面](https://steamcommunity.com/sharedfiles/filedetails/?id=3800734754)，点击“订阅”。
2. 等待 Steam 下载完成，完全退出并重新启动游戏。
3. 在游戏模组列表中启用“同名卡牌编号 (Card Copy Numbers)”。

### 方法二：本地安装

1. 从本仓库的 **Releases** 页面下载 **`CardCopyNumbers-1.2.0-Local.zip`**。请使用这个安装包，而不是 GitHub 自动生成的 `Source code` 源码压缩包。
2. 关闭游戏。在 Steam 库中右键《杀戮尖塔 2》，选择 **管理 → 浏览本地文件**，打开游戏安装目录。该目录中应有 `SlayTheSpire2.exe`。
3. 在游戏安装目录下找到或新建 **`mods`** 文件夹。
4. 解压安装包，把里面的整个 **`CardCopyNumbers`** 文件夹放入 **`mods`**。

正确的目录结构如下：

```text
Slay the Spire 2/
├── SlayTheSpire2.exe
└── mods/
    └── CardCopyNumbers/
        ├── CardCopyNumbers.dll
        └── CardCopyNumbers.json
```

Steam 默认位置通常为：

```text
C:\Program Files (x86)\Steam\steamapps\common\Slay the Spire 2\mods\CardCopyNumbers\
```

如果游戏安装在其他磁盘，请以 Steam 的“浏览本地文件”打开的目录为准，例如：

```text
D:\SteamLibrary\steamapps\common\Slay the Spire 2\mods\CardCopyNumbers\
```

不要把 ZIP 原封不动放入 `mods`，也不要多套一层 `CardCopyNumbers` 文件夹。两份文件应直接位于上面展示的目录中。

5. **通过 Steam 正常启动游戏**，在模组列表中启用本模组。第一次使用模组时，按游戏提示确认并重启。
6. 检查模组详情中的版本是否为 **1.2.0**、作者是否为 **祁若泫**，然后进入战斗即可使用。

安装包中的 DLL 不需要单独运行。玩家无需安装 .NET SDK、开发工具或官方工坊上传器，也无需复制游戏 DLL。

### 更新与卸载

- **更新本地版：** 关闭游戏，用新版安装包中的两个文件替换 `mods/CardCopyNumbers` 内的旧文件，再重启游戏。
- **卸载本地版：** 关闭游戏，删除或移出 `mods/CardCopyNumbers` 文件夹。
- **切换安装方式：** 使用工坊版前移除本地版；使用本地版前取消工坊订阅，避免加载到非预期版本。
- Steam 在游戏运行期间下载的新版本，需要完全退出并重启游戏后才会加载。

## 使用建议

本模组可独立使用。如果需要查看真实抽牌顺序，可另行订阅“随机数预测”，并在其设置中开启冻结之眼。普通牌堆浏览仍按同名牌编号整理显示；冻结之眼显示保留牌堆顺序。

例如使用“冲锋！！”选择抽牌堆中的卡牌时，可通过尾缀区分多张凋萎，再对应它们在冻结之眼中的位置。

## 兼容说明

- 当前版本针对游戏 **v0.111.0** 构建，已适配 **RandomForeseer 0.13.14** 的相关功能。游戏或其他模组更新后，兼容性可能需要重新确认。
- 相同卡组与相同生成顺序有助于重开战斗后复现编号；其他模组提供的战斗中快照回退不保证保留相同编号。
- 多人模式及完全替换卡牌名称或牌堆界面的第三方模组尚未全面验证。
